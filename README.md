# Alpha Combination Lab

How should a portfolio manager combine many noisy, correlated return signals? This repository tests seventeen
combination methods, from equal weights to gradient boosting and dynamic model averaging, on sixteen published
US-equity signals in the S&P 500 from 1980 to 2024, strictly out of sample, after costs.

Status: protocol pre-registered (`experiments/preregistration.md`); experiments running. Results and the full
report will be added here.
